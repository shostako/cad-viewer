# cad-viewer

自作CADビューア。STEP/IGES・STL/3MF・DXF/DWG の閲覧＋計測・注記・断面（形状編集はしない）。

版ごとの変更は [CHANGELOG.md](CHANGELOG.md) にある。

## アーキテクチャ

```
[WSL2] FastAPI + OCP(OpenCASCADE) ──localhost──> [Windows] ブラウザ (Three.js + TypeScript)
        B-rep読込・テッセレーション・真値計測         描画・ピッキング・UI
```

設計原則: **メッシュは表示用の嘘、計測はB-repの真実**。
テッセレーションメッシュにはトポロジID（face/edge/vertex）を付与して配信し、計測は必ずサーバ側でOCCTの真値計算を行う。

## 起動（日常使い）

**Windows デスクトップの `cad-viewer.vbs` をダブルクリック** → backend が起動し、
既定ブラウザで開く（コンソール窓は出ない）。既に起動済みならブラウザを開くだけ（冪等）。
git pull などで frontend のソースが `dist` より新しければビルドし直し、start.sh が立てた
backend より backend のコードが新しければ backend を立て直す。

内部では frontend を同梱した backend を **1プロセス(:8008)** で立てている（Vite dev
サーバは不要）。WSL から直接なら:

```bash
./start.sh          # frontend/dist を配信する backend を :8008 で立て、ブラウザを開く
```

初回セットアップ（マルチPC再現）:
1. `backend/.venv` を用意（下の「開発」参照）、`frontend` で `npm install`
2. `launcher/cad-viewer.vbs` を Windows デスクトップにコピー
   （既定の WSL distro（`wsl.exe -l -v` で * の付いたもの）で起動するので編集は不要）
3. `./start.sh` を一度叩くと `frontend/dist` が自動ビルドされる

> single-server の仕組み: `frontend/dist` が存在すると `backend/app/main.py` が
> それを `/` にマウントして配信する（`/api/*` は既存ルートが優先）。dist が無い開発
> 時は下記の dev サーバ構成にフォールバックする。

## 開く・読み込み中・開けなかったとき

- 何も開いていない画面では、真ん中に「CAD ファイルを開く」のカードが出る（「ファイルを選ぶ」か、画面のどこかにドロップ）
- **最近開いたファイル**: 「ファイルを選ぶ」・ツールバーの「ファイルを開く」で選んだファイルを、新しい順に 8 件まで覚える（このブラウザの中だけ。サーバーには送らない）。ドロップしたファイルも、ブラウザが手がかりを渡すとき（Chrome でエクスプローラーから落としたとき）は覚える。何も開いていない画面のカードと、ツールバーの「ファイルを開く」の右の ▾ に一覧が出る。行を押すとそのファイルを開き直す（Chrome がもう一度読む許可を聞くことがある）。計測と注記は、同じ中身のファイルと同じく戻る。× で一覧から消す（ファイルはそのまま）
  - 同じファイルをもう一度開くと、一覧の上へ動く（2 行にならない）。9 件目を開くと、いちばん古いものが消える
  - ファイルを動かしたか消したときは、行を押すと左下に「見つからない」と出し、その行を消す。読む許可を断ったときは、左下にそう出し、行は残す（もう一度押すと、また許可を聞く）
  - 覚えるのはファイルの手がかり（File System Access）で、Chrome・Edge だけ。ほかのブラウザでは「ファイルを選ぶ」はふつうのファイル選択になり、一覧には入らない。ファイルを選ぶ画面は、前に開いたファイルのフォルダから始まる
- 開いているファイルの名前をブラウザのタブ（タスクバー）の題名に出す（`mini_mold.step — cad-viewer`）。いくつも開いても見分けられる
- 読み込み中は、真ん中のカードにファイル名と大きさ、いまの段階（送信 → 形状の変換 → 表示の準備）と進み具合の帯を出す。送信のあいだは送った割合、そのあとは残りの時間が分からないので動く帯。2 回目以降の読み込みでも出る
- 開けなかったときは、真ん中のカードに理由をふつうの言葉で出す（対応していない形式、読めない（壊れているか、対応していない書き方）、大きすぎる（500 MB まで）、空のファイル、backend につながらない、形状の変換の途中で通信が切れた、形状を受け取れなかった）。backend の元の文は「詳細を見る」で見られる。「別のファイルを選ぶ」でファイルを選び直し、「閉じる」か Esc でカードを閉じる（何も開いていなければ「CAD ファイルを開く」のカードに戻る）。前に開いていたモデルは、送信や変換で失敗したときはそのまま残る
- カードは操作パネルの左の範囲の真ん中に置く（パネルに隠れないように）。窓が狭くて入らないときは画面の真ん中に、パネルの上に重ねて置く

## 画面の操作

右上のツールバーに、よく使う操作を並べてある（左から）: ファイルを開く（右の ▾ で最近開いたファイル）・全体表示｜回転・計測・注記｜断面・表示スタイル・画像を保存・キー操作の一覧。いまのモードと、断面を入れているあいだの断面のボタンは、押された見た目（青）になる。ボタンにカーソルを乗せるとキーを含む説明が出る。

- キー: M で計測、N で注記（もう一度押すと回転に戻る）、S で断面を入れる・切る、W で表示スタイルを順に（陰影＋稜線 → 陰影のみ → ワイヤーフレーム → 半透明）。注記の入力中に打った文字は、キーとしては働かない
- メッシュ形式（STL など）では計測のボタンが薄くなる（押すと、計測できない理由を左下に出す）。2D 図面では注記・断面・表示スタイルを押せない（M で計測はできる）
- 何も開いていない画面で押せるのは、ファイルを開く（と ▾）・表示スタイル・キー操作の一覧だけ
- ファイルを開く・全体表示・画像を保存はツールバーだけにした（操作パネルの行を減らして、右半分の窓でも操作パネルがスクロールしないように）。操作パネルにはモード・計測クリア・画像の背景と、各フォルダが残る。「表示」フォルダは初めは畳んである（表示スタイルはツールバーと W で変えられる。開け閉めは記憶する）
- アイコンは Lucide（ISC ライセンス）を同梱している。実行時にネットにはつながない

| 操作 | マウス | キーボード |
|---|---|---|
| 回転 | 左ドラッグ | 矢印キー（押した側の面が見えてくる） |
| 移動 | 右ドラッグ | Shift + 矢印キー |
| 拡大・縮小 | ホイール（カーソルの下の点に向かって寄る） | ＋ ／ −（回転の中心に向かって） |
| 回転の中心 | モデルをダブルクリック（モードが「なし」のとき） | — |
| 全体表示 | ツールバーの全体表示 | F または Home |
| 軸の向きから見る | 左下の座標軸の端の丸をクリック | — |
| 肉厚・勾配の値を読む | 肉厚ヒートマップか抜き勾配の色分けを出しているあいだ、面にカーソルを乗せる（カーソルの横に出る） | — |
| パネルを隠す・出す | 操作パネルの見出しの「隠す」／右上の「パネルを出す」 | H |
| 計測・注記にする | ツールバーの計測・注記（回転で戻る） | M ／ N（もう一度で戻る） |
| 断面を入れる・切る | ツールバーの断面 | S |
| 表示スタイルを変える | ツールバーの表示スタイル（順に） | W |
| 計測の 1 点目を取り消す・モードをやめる | — | Esc |
| 1 点目の面積・周長、稜線の長さを一覧に入れる | 計測で面か稜線を 1 点目に選ぶ（左下に値が出る） | Enter |
| 消した計測を戻す | 左下の「元に戻す」（消してから 8 秒） | Ctrl + Z |
| クリックで選ばれるものを先に見る | 計測・注記のモードで、モデルにカーソルを乗せる（水色で示し、カーソルの横に名前が出る） | — |
| どの部品かを見る | 部品ツリーの行にカーソルを乗せる（3D でその部品が光る）。モードが「なし」なら、3D の部品にカーソルを乗せる（ツリーのその行に印が付く） | Tab で行に入る（その部品が光る） |
| 1 つの部品だけを見る | 部品ツリーの行の「これだけ表示」。戻すのはツリーの見出しの「全部表示」 | Tab で行のボタンへ進み Enter |
| 1 つの部品に寄る | 部品ツリーの行の「この部品へ寄る」 | Tab で行のボタンへ進み Enter |
| 部品ツリーを畳む・広げる | ツリーの見出しの「部品ツリー」 | Tab で見出しへ進み Enter |
| キー操作の一覧を開く・閉じる | 左下の状態表示の右端の「?」 | ?（閉じるのは Esc でも） |

左下は状態表示の 1 行（窓が狭くて入らないときは折り返し、文を切らない）と、その右端の「?」だけにした。マウスとキーの操作は「?」か ? キーで開く一覧にある（3D と 2D 図面で別の一覧）。一覧は状態表示と座標軸の上に出し、開いたままでもマウスとキーはそのまま使える（試しながら読める）。もう一度 ?、Esc、× で閉じる。計測の途中で一覧を開いていても、Esc はまず一覧を閉じる（計測はそのまま）。一覧の下にこのアプリの版を出す。

パネルを隠すと、ツールバー・操作パネル・部品ツリー・計測の一覧・体積・重量が消え、左下の状態表示（右端の ? も）と座標軸だけが残る。全体表示のあと視点を動かしていなければ、空いた範囲にモデルを収め直す（画面の右半分の窓で幅が約 1.5 倍になる）。動かしたあとの視点はそのままにする。

全体表示はいまの向きのまま、見えている部品の全体を、パネルに隠れない範囲の約 9 割に収め、その範囲の真ん中に置く（隠した部品は含めない）。新しいモデルを開いたときは斜め上からの向きで表示する。

視点のボタン、座標軸の端のクリック、全体表示（F・ツールバー・この部品へ寄る・パネルを隠したり出したりしたときの収め直し）は、0.3 秒ほどかけて新しい視点へ滑らかに動く（ゆっくり始まり、ゆっくり止まる）。動いている途中でキーやマウスを使うと、動きはその場で行き先に着いてから、その操作が効く。モデルを開いたときの全体表示は動かさない（すぐその視点で出す）。OS の設定で「アニメーションを減らす」にしていると動かさない

何も動いていないあいだは描画を止める（ノート PC の電池・発熱・ファンの音のため。前は止まったモデルも 1 秒に 60 回描いていた）。マウス・キー・パネルの操作、計算の結果（肉厚の色、計測の値）が届いたとき、窓の大きさを変えたときは、すぐ描き直す。自動回転のあいだは描き続ける。止まっているあいだも 1 秒に 1 回は描く

- **パネルに隠れない範囲**: 画面のうち、右上の操作パネル・左上の部品ツリー・左下の案内・右下の計測の一覧と体積・重量のパネルのどれにも重ならない長方形（幅と高さが画面の 4 割以上）。細長い部品の端がパネルの下に潜らないようにするため
  - ふつうはそのうちいちばん広い長方形を使う。いまの向きで見たモデルの縦横の比に合う長方形が別にあり、そちらだとモデルが 1.1 倍以上大きく映るときは、いちばん大きく映る長方形を使う（たとえば横に長い製品を正面から見たときは、部品ツリーの横の縦長の範囲ではなく、その下の横長の範囲に収める）
  - 倍率が 1.1 倍に満たないときに広い長方形のままにするのは、わずかに大きく映るだけでモデルが画面の別の場所へ飛ばないようにするため
- その範囲は全体表示をした瞬間のパネルの大きさで決める。あとでパネルの大きさが変わっても（フォルダの開け閉め、計測の一覧が伸びる など）表示は動かない。収め直すには F を押す
- 開いたときの全体表示は、部品ツリー・保存してあった計測の一覧・体積・重量の値がそろってから 1 回だけ行う（体積・重量のパネルは値が出ると部品の数だけ広がるので、その大きさを避ける）。体積・重量の計算が頼んでから 1.5 秒たっても終わらないとき（大きな B-rep を、backend を立て直したあとで初めて開いたとき など）は待たずに「計算中…」のパネルを避けて収める。そのあと値が出てパネルが広がっても表示は動かないので、モデルの端が隠れたら F を押す
- その範囲が画面の幅か高さの 4 割に満たないとき（とても狭いウィンドウ）は、パネルを避けずに画面全体に収める
- 回転・視点の切り替え・＋／−・自動回転は、その範囲の真ん中（表示の中心）を中心にする。ウィンドウの大きさを変えても、表示の中心はパネルを避けたぶんだけずれたまま（画面の幅・高さの 3 割まで）
- ダブルクリックした点は、向きと大きさを変えずに全体表示で決めた表示の中心へ滑らせ、以後の回転の中心になる
- 2D 図面では F・Home で図面全体を画面全体に表示する（パネルは避けない）

左下の座標軸（X 赤・Y 緑・Z 青）は、いまの向きでモデルの軸がどちらを向いているかを示す。文字の入った丸が + の端、小さい丸が − の端で、手前にある端が上に重なる。端の丸をクリックすると、その側から軸に沿って見る（視点のボタンと同じ: +X＝右、−X＝左、+Y＝背面、−Y＝正面、+Z＝上、−Z＝下）。座標軸のクリックはモデルに届かない（計測の点や回転の中心にはならない）。ホイールは座標軸の上でもカーソルの位置へ拡大縮小する。座標軸は 3D モデルを開いているときだけ出し、画像の保存には入らない。

面は、部屋の柔らかい光（あらゆる向きから、向きによって違う量で来る）と、斜め上からの主光で照らす。上を向いた面がいちばん明るく、下を向いた面がいちばん暗く、横の面も向きによって明るさが違うので、向きの違う面を見分けやすい（開いたときの視点で一緒に見える上・正面・右の 3 面は、はっきり違う明るさになる）。光は明るさだけを変え、部品の色合いは変えない。

右上の「表示」フォルダ:
- **表示スタイル**: モデルの描き方を切り替える
  - 陰影＋稜線（既定）: 面と稜線
  - 陰影のみ: 面だけ。稜線を描かない
  - ワイヤーフレーム: 稜線だけ。面を描かない。稜線を持たない STL などは三角形の辺を描く
  - 半透明: X 線のように面を透かし、稜線は残す。金型の中の部品（ピン・入れ子）を見るためのもの
  - 線だけの部品（IGES の「曲線（N 本）」）は、どのスタイルでも黄色の線のまま描く（線しかないので、陰影のみでも消さない）
  - どのスタイルでも、面はクリックで選べる（計測・注記・ダブルクリック・ホイール）。ワイヤーフレームで描いていない面も、カーソルの下にあれば選ばれる
  - ワイヤーフレームと半透明では、描いている稜線の近くをクリックすると、手前の面よりもその稜線を取る（端の頂点の近くなら頂点）。ほかの部品の奥にある稜線も同じ。線の近くでなければ、一番手前の面を取る。奥の部品の面を計るときは、部品ツリーで手前の部品を隠すか、断面で切る
  - 部品が 2 つ以上あるモデルでは、計測の案内と一覧に部品の名前も出す（例: `cavity_block 面#6`、`core_pin エッジ#2`）。手前と奥のどちらの部品を取ったかが分かる
  - ワイヤーフレームと半透明では、稜線を部品の色で描く（暗い背景で見えるように。暗い色は明るくして描く）
  - 陰影のみでも、計測は描いていない稜線にスナップする
  - 肉厚ヒートマップの色は、陰影＋稜線・陰影のみ・半透明で見える。STEP・IGES のワイヤーフレームでは面を描かないので見えない（左下の案内にもそう出る）。STL などのワイヤーフレームでは三角形の辺に色が付く（案内には出ない）
  - 断面のキャップ（切り口のふさぎ）は、陰影＋稜線・陰影のみでは不透明、ワイヤーフレーム・半透明では半透明にする（切り口の奥の部品が見えるように）
  - 切り替えても形状は作り直さない（描き方の設定だけを変える）ので、大きなモデルでもすぐ切り替わる。STL を初めてワイヤーフレームにするときだけ、三角形の辺の一覧を一度作る
- **グリッド**: 床の格子の表示・非表示
- **自動回転** と **回転速度**: 縦軸のまわりに回し続ける（ドラッグ中は止まる）。回転速度は自動回転を入れているあいだだけ出す
- **回転方式**: ターンテーブル（Z 軸を常に上に保つ。CAD の標準）／自由回転（上を越えて裏返せる）。
  自由回転で裏返した状態からターンテーブルに戻すと、Z 軸が上に戻るので画面が回って見える
- **投影**: 透視（遠いものほど小さく見える）／平行（正射影。奥行きで大きさが変わらず、平行な稜線は画面でも平行。正面や上から見ると図面と同じ縦横の比になる）。
  切り替えても向き・回転の中心・目標点での大きさは変わらない。平行でも全体表示・カーソルの位置への拡大縮小・ダブルクリックの回転の中心・計測・断面・画像の保存はそのまま使える。拡大縮小の限度は透視と同じ倍率
- **視点**: 正面・背面・右・左・上・下・等角へ切り替える（上・下は +X が右）。ボタンは 4 列に並ぶ

グリッド・回転速度・回転方式・表示スタイル・投影はブラウザに記憶する。操作パネルのフォルダの開け閉めも記憶する（初めは「表示」と「視点」を開き、ほかは畳む）。何も開いていない画面ではフォルダを全部畳み、モデルや図面を開くと記憶した開け閉めに戻す。何も開いていない画面の操作パネルは「表示」（先に決めておけて、次に開くファイルにも効く）だけで、モード・計測クリア・画像の背景と、モデルに効くフォルダ（断面・肉厚・抜き勾配・体積・重量）はファイルを開くと出る。

いま画面に出ているものを報告書などに貼るときは、ツールバーの画像を保存を使う（下の「画像を保存（PNG）」）。

右上の「モード」で「計測」を選ぶと、2 回のクリックで 2 点（面・稜線・頂点）のあいだの最短距離を B-rep の真値で測る。1 点目に曲がった面か稜線を選ぶと、その大きさも 1 行足して一覧に入る:

- 円の全周（穴・ボス）の円筒面と円の稜線は直径 `⌀6.000`、一部（フィレット・角の丸み）は半径 `R5.000`（稜線は長さも出す）
- トーラス面（円の稜線に沿ったフィレット）は小さいほうの半径 `R1.000`、球面は `SR4.000`、円錐面は片側の勾配 `勾配 2.000°`
- B スプラインで書かれた面・稜線（IGES に多い）は、円筒・球・円錐・平面・円と 0.0001 mm 以内で一致すれば、そのものとして扱う
- それ以外の曲がった B スプラインは、クリックした点での曲率半径（その点でいちばん強く曲がる向きの半径）を `R1.000` と出し、一覧に「（クリックした点）」と書く

1 点目に選んだ面と稜線は、それだけで測れる量も左下の案内に出す。面は面積と周長（外側の輪郭の長さ）で、内側にも輪郭（穴・ボスの付け根・くぼみの縁）があればその数も出す。稜線は長さ（例: `（選んだもの）を選択（面積 6000.000 mm²・周長 320.000）— 相手をクリックで 2 点目、Enter で一覧へ（Esc で取り消し）`）。

- Enter で一覧に入れ、1 点目の選択を終える（次のクリックはまた 1 点目）。面は「面積」と「周長」の 2 行で、内側の輪郭の長さは周長の行の 3 行目に長い順に出す（`内側の輪郭 3 個: 43.767・21.766・18.850`）。稜線は「長さ」の 1 行
- 2 点目をクリックすれば、今までどおり 2 点のあいだの距離を測る（面積などは一覧に入れない）。頂点にはそれだけで測れる量がないので、Enter は何もしない
- 値は backend の OCCT が B-rep から出す。面積は面の上の積分（BRepGProp）。周長は外側の輪郭の稜線の長さの和で、円筒などの面の継ぎ目（同じ稜線を行って戻る）と、長さのない稜線（球の極など）は入れない
- 一覧の印とコピーの種類は「面積」（単位 mm²）・「周長」・「長さ」（単位 mm）。3D の札は面積が `6000.000 mm²`、周長が `周長 320.000 mm`、長さが `長さ 100.000 mm`

2 点目で測る距離は、計測のモードのあいだ操作パネルに出る「距離」で選ぶ（最短・中心間・最大。初めは最短）。最短のほかを選ぶと、1 点目のあとの案内が `相手をクリックで中心間を測る` のようになる。

- **最短**: 今までどおり、2 つのあいだの最短距離（BRepExtrema）。平らな 2 つが平行でなければ角度の行も足す
- **中心間**: 2 つの中心のあいだ。穴のピッチやボスの位置を測るためのもの
  - 中心は、頂点・円や楕円の稜線・球の面では点、円筒・円錐・トーラスの面では軸（B スプラインで書かれた円筒なども、認識できればそのものとして扱う）
  - 点どうしは点のあいだ、点と軸は点から軸までの垂線、軸どうしは平行なときだけ軸のあいだ（クリックした所を横切る線で引く）
  - 平面・直線の稜線などは中心を持たず、軸どうしが平行でないときも測れない。そのときは一覧に入れず、左下に理由を出す（例: `中心間は測れない — 1 点目: 平面に中心はない`、`軸が平行でない（90.0°）`）。ほかの距離で代わりに測ることはしない
- **最大**: 2 つの点のあいだのいちばん長い距離。頂点と稜線どうしで出す（面どうしの最大は定義が要るので出さない。面を選ぶと理由を出す）。全長や対角を測るためのもの
  - 頂点と稜線は、稜線の上でいちばん遠い点（OCCT の Extrema が出す点と両端から選ぶので厳密）。稜線どうしは、両方を長さで等分した 64 点ずつで刻み、まわりより遠い組から互いにいちばん遠い点を交互に取り直して詰める（直線は端、円は向こう側の点で止まり、厳密）。B スプラインどうしは探して詰めるので、刻みより短い山は理屈の上では取りこぼしうる
- 一覧の行は値の前に `中心間 26.000 mm`・`最大 65.192 mm` のように付け、印も変える。コピーの種類は「中心間」「最大」（値は数だけ）。3D の札も `中心間 26.000 mm`。サイドカーに保存し、開き直すと戻る
- 2D 図面では出さない（図面の計測は端点・中心へのスナップ）

「注記」は、クリックした点に文を付ける。

- **寸法線を引く所**: 値はいつも B-rep の最短距離。2 つの平行な平面のように、最短の所がたくさんある（重なっている所ならどこでも同じ）ときは、クリックした所に線を引く（片方のクリックを通って、両方の面に直角に）。クリックした所で 2 つの面が向き合っていなければ、BRepExtrema の解のうちクリックにいちばん近いものに引く（今までは最初の解で、角に引かれることが多かった）

- **クリックで選ばれるものを先に見る**: 計測・注記のモードでモデルにカーソルを乗せると、そこをクリックしたら選ばれるものを水色で示す。面は塗り、稜線は太い線、頂点は輪。カーソルの横には計測の一覧と同じ名前を出す（例: `cavity_block · 面#6`、部品が 1 つのモデルでは `面#6`）。クリックと同じ選び方（頂点は 14 px、稜線は 10 px 以内にスナップ）なので、示したものがそのまま選ばれる。小さな窓で頂点に吸われる、手前の部品の面に当たる、といったことをクリックの前に分かる
  - 曲がった面と稜線は、カーソルを 0.15 秒ほど止めると、上の大きさ（⌀・R・SR・勾配）を backend に問い合わせて名前に足す（例: `core_pin · エッジ#1 ⌀8.000`）。クリックした点での曲率半径は出さない（面の上で変わるため。クリックで測る）。頂点は B-rep の座標を足す（例: `plate · 頂点#3 (100.000, 0.000, 15.000)`）。答えはモデルごとに覚えておき、同じものの上では問い合わせ直さない
  - 1 点目を選んだあとは、1 点目からカーソルの下の候補まで水色の点線を引く
  - 消えるとき: クリックした（次にカーソルを動かすまで出ない）、ドラッグのあいだ、ホイールのあと、モデルの外、ビューの外（パネルの上）、モードを「なし」にした。計測の答えを待っているあいだ（その間のクリックは効かない）も出さない
  - 水色の表示とカーソルの横の名前は、画像の保存に入らず、全体表示にも関わらない
  - 肉厚ヒートマップや抜き勾配の色分けを出していても、計測・注記のモードでは、クリックで選ばれるものの名前を値より優先して出す。メッシュ形式（STL など）のモデルには選べる B-rep の面・稜線・頂点がないので、水色の表示は出さず、色分け中なら値を出す
  - 2D 図面では出さない（図面の計測は端点・中心・四分円点へのスナップ）
  - 半透明・ワイヤーフレームでは、選ぶたびに描いている稜線をすべて調べる。稜線の多いモデルでも重くならないよう、カーソルを乗せたときは、1 回の調べにかかった時間の 4 倍だけ待ってから次を調べる（待つあいだは前の表示のまま。止まった所はそのあとで調べる）。クリックはいつでもすぐ調べる
- 左下の案内は、計測モードに入ると「計測: クリックで 1 点目（Esc でやめる）」、1 点目を選ぶと「（選んだもの）を選択 — 相手をクリックで 2 点目（Esc で取り消し）」（面と稜線は、backend の答えが来たところで面積・周長か長さを括弧に足し、「Enter で一覧へ」を加える）、2 点目を選ぶと距離を出す。選んだ 2 つがどちらも平ら（平面か、真っ直ぐな稜線）で平行でないときは、その角度（0〜90°。面どうしは法線、稜線どうしは向き、稜線と面は稜線と面のなす角）も出し、一覧に「角度」の行を 1 つ足す（例: ブロックの上面と側面は `距離 0.000　角度 90.000°`）。値は backend の OCCT で出す。Esc で 1 点目を取り消すと、そこから引いていた点線もすぐ消える。注記モードでは「注記: クリックした点に注記を付ける（Esc でやめる）」。計測・注記のままモデルを開くと、開いたモデルの概要のあとに同じ案内を続ける。モードを「なし」にすると、クリックを促す行は元の行（モデルの概要か肉厚の行）に戻る（計測の結果は残る）

計測と注記はモデルごとに backend に保存し（サイドカー）、同じファイルを開き直すと戻る（2D 図面の計測は保存しない。下の「2D 図面」）。「計測クリア」や一覧の × で消したあと 8 秒は、左下に出る［元に戻す］か Ctrl+Z で消す前に戻せる（2D 図面の計測も同じ）（ほかの計測を足したり別のファイルを開いたりすると戻せなくなる）。計測の一覧の行は、値を先に単位付きで大きく出し（`20.000 mm`、`⌀8.000 mm`）、何を計ったか（`cavity_block 面#6 ↔ plate 面#6`）を下の行に小さく出す。斜めの距離（2 つ以上の軸に沿って伸びるもの）は、その下にもう 1 行、X・Y・Z の成分（`ΔX 30.000　ΔY 15.000　ΔZ 20.000`。向きは付けない大きさ）を出す。円の稜線の直径は、その下に中心の座標（`中心 (75.000, 30.000, 40.000)`）を出す。どれも backend の真値から出す。左の印で種類（距離・直径・半径・角度・勾配・面積・周長・長さ・注記）が分かる。3D の札にも mm を付ける（注記は書いたまま。保存する形は変えていない）。行の右のコピーの印でその行を、一覧の見出しの「すべてコピー」で全部を、タブ区切りの行（種類・値・単位・対象 A・対象 B・ΔX・ΔY・ΔZ。見出しの行付き。ΔX〜ΔZ は距離の成分で、ほかの行では空）としてクリップボードに入れる。Excel にそのまま貼るとセルに分かれる（直径・半径・勾配の値は数だけ）。文字を選んでコピーすることもできる（値をダブルクリックすると、その数だけを選ぶ）。同じ所に札が重なるときは、後から作った札を下へずらして、どの札も読めるようにする（先に作った札はその場に残る）。行にカーソルを乗せると、3D でその札・寸法線・点が水色に光る。3D の札にカーソルを乗せると、一覧のその行が光る（札はクリックを取らない。札の上のクリックはそのまま下のモデルに届く）。計測モードで 1 点目を選んだあとの Esc はその点を取り消し、もう一度 Esc で計測モードをやめる（注記モードも Esc でやめる）。注記の入力欄は、Enter のほか、ほかの所をクリックしても確定する（取り消しは Esc）。入力中に別のファイルを開くと、その注記は元のモデルに保存する。保存したものの一部が読めないとき（手で書き換えて壊れた など）は、読めたものだけを戻し、左下の案内に何件を戻せなかったかを出す。サイドカーのファイルそのものが読めないとき（壊れている など）は、計測なしで開き、左下の案内に理由を出す。そのまま計測すると新しいサイドカーを保存し、読めなかったファイルは上書きせず `backend/.sidecars/` に `<元の名前>.unreadable-<日時>.json` として残す。どちらでもモデルは開き、全体表示する。

何も開いていない画面の中央には「ファイルを選ぶ」ボタンとドロップの案内を出す。

左下の状態表示は、開いたファイルの名前、部品と三角形の数、大きさを出す（`mini_mold.step — 4 部品・304 三角形・100.0 × 60.0 × 40.0 mm`）。STEP と IGES は読み込みで mm にそろう（OCCT がファイルの単位、m や inch を mm に直す）ので mm を付ける。STL・3MF・OBJ・PLY はファイルの数のままなので単位を付けず、「（単位はファイルのまま）」と書く。2D 図面は `plate_drawing.dxf — 2D 図面・200.0 × 100.0（計測で端点・中心に吸い付く）`。

2D 図面（DXF/DWG）を開いているあいだは、3D 用の項目（表示・断面・肉厚・抜き勾配・体積・重量）を隠し、モードの「注記」は選べない（図面では計測だけ）。キー操作の一覧（?）も 2D 用に切り替わる。

## 部品ツリー

左上の部品ツリーは、部品を 1 つずつ扱うときの起点。部品が 2 つ以上あるモデルと、STEP・IGES のモデルで出る（部品が 1 つの STL などでは出さない）。

- 行には、表示・非表示のチェック、部品の色の印、名前が並ぶ。色の印は 3D でその部品を描いている色（ファイルの色、色の無い部品は既定の薄い青、線だけの部品は黄色）
- 同じ名前の部品が 2 つ以上あると、名前の横に上から順に小さな番号が付く（`core_pin 1`、`core_pin 2`）。順はファイルの中の順
- 行にカーソルを乗せると、3D でその部品が光る（面が水色を帯び、稜線が水色になる。陰影のみでも稜線を出す。線だけの部品は線が水色になる）。グループの行では中の部品が全部光る。カーソルが行から離れると消える。行の中を押したあとは、カーソルを動かすまで光らない（押した結果を部品の本来の色で見るため）。光りは画像の保存には入らない
- モードが「なし」のとき、3D で部品にカーソルを乗せると、ツリーのその部品の行に印（水色の帯）が付く。ツリーがスクロールしていれば、その行が見える所まで送る。計測・注記のモードでは付けない（クリックで選ぶ面・稜線・頂点を見るモードなので）
- カーソルを乗せた行（キーボードで入った行も）の右に 2 つのボタンが出る:
  - **これだけ表示**: その部品だけを残し、ほかを隠す。グループの行では、そのグループの部品だけを残す
  - **この部品へ寄る**: その部品を、全体表示と同じ決まりで収める（向きはそのまま、パネルに隠れない範囲の約 9 割に、その範囲の真ん中に）。グループの行では、そのうち見えている部品を収める。隠している部品には寄れない（ボタンが押せない）。寄ったあと視点を動かさずに H でパネルを隠すと、同じ部品を空いた範囲に収め直す
- 見出しの「部品ツリー」を押すとツリーを畳む（もう一度で広げる）。横の数は部品の数。「全部表示」は隠した部品を全部表示する（全部見えているときは押せない）
- グループのチェックは、中の部品が全部見えていればチェック、一部なら「−」、1 つも見えていなければ空になる。「−」のときに押すと全部を隠す（もう一度で全部を表示）
- キーボード: Tab で見出しのボタン、各行のチェックとボタンに進み、Enter で押す（チェックは Space）。キーボードで入った行の部品も光る
- ボタンは見えないあいだも場所を取っている（カーソルを乗せてもツリーの大きさが変わらず、全体表示の範囲が動かない）

## 2D 図面（DXF/DWG）

DXF はそのまま、DWG は ODA File Converter で DXF にしてから開く（backend が ezdxf で SVG にする）。

- 図面は 3D と同じ暗い背景（#1d2126）の上に描く。図面の外も同じ色。線と文字は図面の色のまま描く。色 7（白／黒）は、暗い背景なので白になる
- ドラッグで移動、ホイールでカーソルの位置へ拡大縮小、F・Home で図面全体を表示する（パネルは避けない）
- 計測モードで 2 点をクリックすると、2 点の距離と ΔX・ΔY（差の大きさ）を出す。クリックは 12 px 以内の端点・中心・四分円点に吸い付く。値は DXF の座標から出す。1 点目を選んだあとの Esc はその点を取り消す
- 計測の点・寸法の線・値は、図面の上に重ねた層に画面の大きさで描く。拡大縮小しても、窓の大きさを変えても、値は 13 px、点は直径 10 px のままで、図面の点の位置に付いてくる
- 計測は右下の「計測」の一覧に 1 件 1 行で出る（値の `100.000` を先に、下の行に `ΔX 100.000　ΔY 0.000`。図面の数は図面の単位のままなので、単位は付けない。コピーでは単位と対象の欄が空で、ΔX・ΔY はそれぞれの欄に入る（ΔZ は空））。行の × でその 1 件を、「計測クリア」で全部を消す。どちらも 8 秒のあいだは［元に戻す］か Ctrl+Z で同じ順に戻せる（消したあとで選んだ 1 点目は残る。新しい計測を足すと戻せなくなる）。値は選んでコピーできる
- 2D 図面の計測は保存しない（サイドカーに書かない）。図面を開き直すと消える
- 画像の保存（PNG）には、いまの移動・拡大のまま、計測の点・線・値も画面と同じ位置・大きさ・色で入る（下の「画像を保存（PNG）」）
- 既知の制限: 黒や濃い青など、暗い色で描かれた線は暗い背景の上では見えにくい（色 7 のほかは図面の色のまま描くため）。「白」の画像では読める

## 断面

ツールバーの断面（S キー）か、右上の「断面」の「有効」で、モデルを 1 枚の平面で切って中を見る。

- 入れたときと軸を変えたときは、カメラのいる側を切り落とす（切り口がこちらを向く）。反対側を残したいときは「反転」
- 「位置 (mm)」は、軸に沿った平面の位置をモデルの座標（mm）で出す。数を打ち込むか、つまみで動かす。軸を変えると、モデルの真ん中から始める
- 平面は、モデルの断面の少し外側に細い枠で描く（前は、モデルより大きな黄色の面で塗っていた）
- 切り口は「キャップ」で塞ぐ（陰影＋稜線・陰影のみでは不透明、ワイヤーフレーム・半透明では半透明）
- 断面は見た目だけで、計測・体積・重量の値は部品全体のまま

## 体積・重量

3D モデルを開くと、右下のパネルに体積・表面積・重量の合計を出す。部品が 2 つ以上あれば、その下の「部品ごとの値（N 部品）」を押すと部品ごとの表が開く（初めは畳んである。開け閉めはブラウザに記憶する）。

- 合計は部品ツリーで表示している部品だけを足す。隠した部品は外れる
- 重量 = 体積（cm³）× 比重。右上の「体積・重量」で樹脂（PMMA・PC・ABS・PP・PA66・POM・PS）を選ぶか、比重を直接入れる（「その他」になる）。樹脂と比重はブラウザに記憶する
- STEP/IGES は OCCT が B-rep の面の上で厳密に積分する（表示用メッシュの粗さに左右されない）。STL などのメッシュ形式は三角形から計算し、単位は mm とみなす
- 閉じていない部品（面に隙間がある、面だけ）や線だけの部品は「体積なし」と出し、合計に含めない。一部だけ閉じた部品も、重量を少なく見せないよう部品ごと「体積なし」にする
- 重なった部品は差し引かずに足す。断面は見た目だけで、値は常に部品全体のもの
- ショット重量の目安にするなら、ランナー・スプルーの分を別に足すこと
- パネルと計測の一覧は、右上の操作パネルの下に収まる高さに縮め、はみ出す分はスクロールで見る。場所が足りないときは、合計、（開いていれば）部品ごとの表の 1 行、計測の一覧、表の残りの順に場所を取る。それでも足りないほど窓が低いときは、表を畳んで合計だけを出す。部品ごとの表を出さないとき（部品が 1 つ、計算中）は、表の分の場所を空けずに計測の一覧に回す
- ただし、操作パネルのフォルダを開いた既定の状態で窓の高さがおよそ 750 px より低いと、表を畳んでも、計測の一覧（× のボタン）や合計の一部が操作パネルの下に入る。そのときは操作パネルのフォルダを畳むか、窓を高くする
- API: `GET /api/models/{id}/properties`（mm³・mm²・重心、丸めない）

### 投影面積と型締力の目安

体積・重量のパネルの合計の下に、型開き方向へ投影した面積と、それに型内圧を掛けた型締力を出す（例: `投影 60.00 cm²（Z・目安）`、`型締力 240.0 kN（24.5 tf・40 MPa）`）。

- 型開き方向は「抜き勾配」の「型開き方向」と同じ設定を使う（＋と−は同じ影になる）。型内圧は右上の「体積・重量」の「型内圧 (MPa)」で入れる（初めは 40 MPa、ブラウザに記憶する）
- 型締力 = 投影面積（mm²）× 型内圧（MPa）＝ N。1 tf = 9806.65 N
- 投影面積は、表示している部品の影の面積（部品どうしや、表と裏の重なりは 1 回だけ数え、貫通穴は抜ける）。肉厚と同じく表示用メッシュから出す目安で、B-rep の真値ではない。曲がった輪郭はテッセレーションの多角形になり、影を細かい画素（影の大きさのおよそ 1 万分の 1）に塗って数えるので、輪郭の長さ × 画素 1 つ分ほどの誤差がある（mini_mold で 0.03 %、厚さ 1 mm の板を真横から見ると 0.2 %）
- 窓が低くて、操作パネルが最小の高さ（160 px）を保てないときは、投影の行を畳んで型締力の行だけを出す。投影面積は型締力の値にカーソルを乗せると出る
- ランナー・スプルーの投影面積は入らない。型内圧は樹脂・肉厚・流動長で大きく変わるので、値は余裕を見て読むこと
- API: `GET /api/models/{id}/projected_area?axis=X|Y|Z&parts=0,1,2&client=…`（mm²。parts を省くと全部品）。計算は 1 つのモデルで 1 本ずつ順に回す。同じページ（client）がもう一度聞いたら、まだ順番待ちの古い方は計算せずに 409 を返す

## 画像を保存（PNG）

ツールバーの **画像を保存** で、いま画面に出ている 3D の表示か 2D の図面を PNG に保存する（ブラウザのダウンロードに入る）。報告書やお客さん向けの資料に貼るためのもの。何も開いていないあいだはボタンを押せない。

- 画像に入るもの: モデル（いまの表示スタイルで。隠した部品は入らない）、稜線、断面、肉厚の色、計測の線と点、寸法と注記の札（画面と同じ位置・色・文字）、グリッド（表示しているとき）
- 画像に入らないもの: 操作パネル、左下の案内と座標軸（肉厚と抜き勾配の凡例も）、部品ツリー、計測の一覧、体積・重量のパネル、カーソルの横の値と名前、計測・注記のモードでクリックで選ばれるものを示す水色の表示、部品ツリーの行に乗せたときの部品の光り。ダブルクリックで出る回転の中心の輪（1 秒で消える目印）も、わざと入れない
- モデルは画面と同じ位置に入る。全体表示はパネルを避けるので、3D ではモデルが画面の中心からパネルを避けたぶんだけずれた位置に入る（ずれる向きはパネルの配置による。右上の操作パネルなら左へ、左上の部品ツリーなら下や右へ）。中央に近づけたいときは、操作パネルを畳んでから F を押して保存する
- 大きさは画面の実際の画素の数（表示の大きさ × 画面の倍率。倍率 2 の画面なら縦横 2 倍）。ページを開いたあとでブラウザの拡大や、倍率の違うモニターへの移動で倍率が変わっても、保存した時点の倍率になる
- **画像の背景**: 「画面のまま」は画面と同じ。「白」は背景を白にし、グリッドを薄い灰色に替える（画面の表示は変わらない）。ワイヤーフレーム・半透明の稜線（部品の色）は、白の上では陰影＋稜線と同じ暗い稜線の色で描く。2D 図面では白い紙になり、白で描かれた線と文字（DXF の色 7 など）を黒にする。黄・シアン・緑などの明るい色は、色合いを保ったまま、白との明暗の比が 4.5:1 になるまで濃くする（黄 #ffff00 は #797900、シアン #00ffff は #008383）。WIPEOUT（下の線を隠す枠）は画面と同じく紙の色、つまり白になる
- 2D 図面は、いまの移動・拡大のまま保存する。計測の点・線・寸法の値も、画面と同じ位置・大きさ（画面の倍率 2 なら縦横 2 倍）・色で入る（「白」でも計測の色は変えない）
- ファイル名は「元のファイル名から最後の拡張子を除いたもの_年月日-時分秒.png」（例: `mini_mold_20261008-143015.png`。時刻はこの PC の時計。`a.b.step` なら `a.b_…`）
- 画像の背景の選択はブラウザに記憶する
- 既知の制限: 「白」では、3D の計測の黄色い線と、2D の寸法の黄色い線が薄く見える（画面と同じ色のまま描くため。2D の寸法の値は暗い縁取りで読める）。2D 図面の明るい色は濃くするので、明るさだけが違う色（色 8 と色 9 の灰色など）は白では見分けにくくなる。STL のワイヤーフレームの線（三角形の辺）は、白でも部品の色のまま描く

## 肉厚

右上の「肉厚」で「ヒートマップ」を入れると、肉厚で部品を色分けする。閾値より薄い壁を見つけるためのもの。左下に凡例が出る。

- 色は閾値のところで切り替わる。閾値未満は赤から橙（閾値の半分までは濃い赤、そこから閾値に近づくほど橙）、閾値以上は灰色がかった青から青（閾値の 2 倍以上は同じ青）。赤か橙なら閾値未満、青の側なら閾値以上
- 閾値は 0.1〜10 mm（0.1 mm 刻み、既定 1.5 mm）
- 凡例: 方式と閾値、0・閾値・閾値の 2 倍に mm の目盛りを付けた色の帯、データなしの色。帯の色は光を当てる前の色で、画面の面は光の当たり方で明るさが変わる
- 方式: レイ法（頂点から面の内側へまっすぐ進んで、向かいの面までの距離。速い。斜めの壁やリブの付け根では厚めに出る）／ローリングボール法（その点で面に接して形の中に収まるいちばん大きな球の直径。遅いが付け根でも正しい）
- データなし（凡例の灰色がかった青）: 肉厚が出なかった点。レイ法で形の外へ抜けた点、ローリングボール法で球が入らない点（角、出っ張った稜線、出っ張った曲面の平らな帯の上の頂点。そこで接する球は、どんなに小さくても隣の面に食い込む。前は計算の許容のぶんだけ入ったことになり、0.0015〜0.1 mm のような薄い壁として赤く出ていた）
- そのため、ローリングボール法では値の出ない頂点が多い。STEP/IGES の表示用メッシュは、平らな面の頂点が縁（稜線の上）にしかなく、ボス・ピン・丸めのような出っ張った曲面は平らな帯でできているから。値が出るのは主に、へこんだ曲面と、へこんだ稜線のそばの頂点。全体はレイ法で見て、リブの付け根などをローリングボール法で確かめる（出っ張った曲面でも値を出す方法は #63 で考える）
- 肉厚は表示用メッシュの頂点ごとに出し、三角形の中は頂点の色をなめらかにつなぐ。頂点の少ない大きな面では、色の境目が閾値の位置からずれて見えることがある。その点の値はカーソルで読む
- **カーソルの下の値**: ヒートマップを出しているあいだ、面にカーソルを乗せると、その点の肉厚（例: `1.20 mm`）をカーソルの横に出す。カーソルの下の三角形の 3 つの頂点の値を、その点の位置で按分した値（データなしの頂点は除いて按分する。3 つともないときは「データなし」）。ワイヤーフレームで面を描いていない STEP/IGES の部品の上では出さない（面は選べるが、何も描いていない所に値を出さない）
  - 出るのは見えている面の値だけ（断面で切った側や隠した部品は出ない）。モデルの外やパネルの上では消える
  - ドラッグ（回転・移動）のあいだとホイールのあとは消え、カーソルを動かすとまた出る。キーで視点を動かしたときなど、カーソルが止まったまま下の面が変わったときは出し直す
  - 計測・注記のモードでは、値の代わりに、クリックで選ばれるものの名前を出す（上の「クリックで選ばれるものを先に見る」）
- **薄い所へ**: 凡例の「薄い所へ」を押すと、閾値より薄い所へ寄る。押すたびに次の所へ、薄い順に回る（最後の次は最初）。凡例の横に「1/3 ・ 1.20 mm」（3 か所のうち 1 番目、その所のいちばん薄い値）と出し、寄った所に黄色の輪と値の札を置く
  - 1 か所は、閾値より薄い頂点が三角形や近さ（閾値ほどの距離）でつながったもの。薄い壁の両側は 1 か所になる。輪はその所でいちばん薄い点に置く
  - 閾値より薄い所が無いときは、いちばん薄い 1 点へ寄り、「閾値より薄い所は無い。いちばん薄い所 8.00 mm」と出す
  - その所の面の向きから見て（横を向いた面は少し上から）、パネルを避けた範囲に収める。ほかの部品の陰にある所でも、輪と札は見える。H でパネルを隠しても、同じ所を収め直す
  - 閾値・方式・表示している部品を変えると、輪と番号は消え、次に押したときに数え直す。隠した部品の所へは行かない。輪と札は画像の保存には入らない
- 抜き勾配の色分けとは同時に使えない（どちらも面の色を使う）。新しいモデルを開くと切れる。2D 図面では使えない
- 計算は backend が表示用メッシュの上で行い（`GET /api/models/{id}/thickness.bin?method=ray|ball`）、モデルと方式ごとに覚えておく

## 抜き勾配

右上の「抜き勾配」で「色分け」を入れると、型開き方向に対する面の傾き（勾配 = 面と型開き方向のなす角）で部品を色分けする。左下に凡例が出る。

- 型開き方向（+Z・−Z・+X・−X・+Y・−Y、モデルの座標軸で決まり、見る向きには関係しない）と必要な勾配（0〜10°、0.1° 刻み）を選ぶ。どちらもブラウザに記憶する（色分けの入り切りは記憶しない）
- 緑＝抜ける側: 型開き方向に必要な勾配以上で傾いた面（真上を向いた面は 90°）。必要な勾配ちょうどの面もここ
- 赤＝勾配不足: 傾きが足りない面。垂直な壁（0°）はここに入る（必要な勾配を 0° にしたときだけ抜ける側）
- 青＝反対側: 逆向きに必要な勾配以上で傾いた面。パーティングラインより反対側（もう一方の型）にある面なら、その型で抜ける。型開き側にある青い壁は逆勾配（またはアンダーカット）で、どちらの型でも抜けない。向きだけでは、この 2 つを見分けられない（パーティングの位置は見ていない）
- 凡例の色は光を当てる前の色。画面の面は光の当たり方で明るさが変わる
- **カーソルの下の勾配**: 色分けしているあいだ、面にカーソルを乗せると、その点の勾配と分類（例: `勾配 2.0°（抜ける側）`）をカーソルの横に出す。型開き方向と反対を向いた面は負の角度（真上の面は 90°、垂直な壁は 0°、真下の面は −90°）。色と同じ向きから出す（STEP/IGES はその点で頂点の法線を按分した向き、STL などはその三角形の向き。下の 2 つを参照）。曲面で色の境目がぼやけているところも、その点の値が読める。消える・出し直す決まりは肉厚の値と同じ
- STEP/IGES は表示用メッシュの法線で頂点ごとに判定する。平らな面は面の向きそのもの、曲面は頂点の向きで近似するので、曲面の上の色の境目は三角形の中でぼやける
- STL などのメッシュ形式は、三角形 1 枚ずつ、その三角形の向き（頂点の並び順から出す）で判定し、平らに塗る。表示用の頂点の向きは 30° より浅い稜線で隣の三角形と平均してあり、それで塗ると、フィレットに続く大きな壁の上の方が、勾配が足りないのに緑に見えてしまうため
- 向きだけで判定するので、ほかの形の陰になって抜けない面（アンダーカット）は見つけられない
- **この色の面へ**: 凡例の「勾配不足」と「反対側」の行の「この色の面へ」を押すと、その色の面へ寄る。押すたびに次の面へ、大きい順に回る（最後の次は最初）。凡例の横に「2/10 ・ 勾配 0.0°」と出し、面の上に黄色の輪と勾配の札を置く
  - STEP/IGES は B-rep の面ごと。曲面の一部だけがその色なら、その部分へ寄る。STL などは、その色の三角形が角でつながった塊を 1 つの面とする
  - 寄り方・輪・数え直しは、肉厚の「薄い所へ」と同じ（型開き方向・必要な勾配・表示している部品を変えると数え直す）
- 肉厚ヒートマップとは同時に使えない（どちらも面の色を使う）。片方を入れると、もう片方は切れる
- 新しいモデルを開くと切れる。断面の切り口（キャップ）は色分けしない
- 面の表裏が正しいことが前提。STEP/IGES のソリッドと、縫い合わせて閉じた形は外向きになっているが、閉じていない形（体積・重量で「体積なし（閉じていない）」と出る部品。ツリーに「サーフェス」と出る縫い合わせた面や、縫い合わせられなかった IGES の面もここ）は、ファイルの面の向きをそのまま使う。緑と青が逆になっていることがあるので、型開き方向を反転して確かめる。赤（勾配不足）は表裏に関係なく正しい。そうした部品があると、凡例に注が出る。STL などのメッシュ形式は三角形の向き（外向き）がそろっていることが前提

## 問題の一覧

右上の「問題の一覧」で「一覧を出す」を入れると、表示している部品を調べて、薄肉・勾配不足・反対側の所を右下に 1 つの一覧にする。行を押すと、その所へ寄る（凡例の「薄い所へ」「この色の面へ」と同じ寄り方）。

- 調べるものは「肉厚を調べる」「抜き勾配を調べる」で選ぶ（どちらも初めは入）。条件は「肉厚」の閾値と方式、「抜き勾配」の型開き方向と必要な勾配で、一覧の上にその条件を出す
  - 肉厚をまだ計算していなければ計算する（ヒートマップと同じ計算で、答えを共有する）
- 行の種類
  - **薄肉**: 閾値より薄い所。薄い頂点のつながり（「薄い所へ」と同じまとまり）で、値はその所でいちばん薄い肉厚。薄い順
  - **勾配不足**: 必要な勾配に足りない面（STEP/IGES は B-rep の面、STL などはその色の三角形のつながり）。値は輪を置く所の勾配で、面積も出す。大きい順
  - **反対側**: 型開き方向と逆を向いた面。もう一方の型で抜く面なら問題ではない（パーティングを確かめるために出す）。大きい順
  - **判定できない**: 体積のない部品（閉じていない、面の向きが不揃いなど。体積・重量のパネルと同じ理由）は、肉厚も面の向きも分からないので調べず、理由を出す。肉厚の値が出ない頂点（ヒートマップのデータなし）がある部品は、その数を出す（レイ法では円筒の縁の頂点で出やすい）
  - 判定できない所は、問題なしとして数えない。どの行もないときだけ「この条件では見つからなかった」と出す
- 行には、値、種類・部品・面の番号（STEP/IGES。計測の一覧と同じ番号）、その所の座標を出す。行の右の印で、その部品だけを表示する（部品ツリーの「これだけ表示」と同じ）
- 行を押すと、その種類の色分け（薄肉は肉厚ヒートマップ、勾配不足・反対側は抜き勾配）に切り替え、その所へ寄って、行を青く囲む
- 条件か表示している部品を変えると、一覧を作り直す（寄った所の輪は消える）。新しいモデルを開くと切れる
- 1 種類につき 50 行まで出し、残りは「ほか N 所」と数だけ出す
- **すべてコピー**: 種類・値・単位・部品・X・Y・Z・面積・条件をタブで区切った行（見出しの行付き）。Excel にそのまま貼れる

## バイナリメッシュプロトコル

`GET /api/models/{id}/mesh.bin` — `[uint32 headerLen][header JSON][buffers...]`
バッファは部品ごとに `p{id}:positions` / `p{id}:normals` / `p{id}:indices` / `p{id}:edges`（線分ペア）。
ヘッダに `parts`（name / color / faceRanges / edgeRanges）と `tree`（アセンブリ階層）。
STL等のメッシュ形式も同じ「1部品」形式に統一（フロントのデコードパスは1本）。
faceId/edgeId は `TopTools_IndexedMapOfShape` のindexで、サーバ側B-repと1:1対応（Phase 2の計測で使用）。

テッセレーション結果は `backend/.cache/` にディスクキャッシュされる（キー: ファイルsha256＋パラメータ）。

## 既知の注意点

- ヘッドレスChromium(SwiftShader)のスクショで右下に白矩形が出るが、WebGL合成アーティファクト（実ブラウザでは出ない）
- 断面キャップはステンシル方式（webgl_clipping_stencil）。three.jsバージョン更新で壊れる前科がある技術なので、更新時は必ずキャップの描画確認をすること。壊れたらGUIの「キャップ」をOFFにすればキャップなし断面で使える
- three.js はバージョン固定（クリッピング断面のステンシルキャップが更新で壊れる前科があるため）
- IGES など、面がバラバラのまま書き出されたファイルは、読み込み時に面を縫い合わせて 1 つの形にする（許容差 0.0001 → 0.001 → 0.01 mm の順に試し、すべて閉じたらソリッドにする。上限はモデルの対角の 1/10000）。小さい部品（対角 10 mm 未満）は 0.0001 mm の段だけを使うので、それより大きいすき間は閉じずにサーフェスのまま残る。色の違う面を縫った形は既定の色になる。縫い合わせに失敗したら、縫わずにそのまま開く。最上位のバラバラの曲線は「曲線（N 本）」の 1 部品にまとめ、黄色で描く。全体表示とサイズ表示は面を持つ形だけで決める（補助線の座標軸などで製品が小さく映らないように）
- 読み込みの結果（部品や面の番号）を変えたら `backend/app/cache.py` の `CACHE_VERSION` を上げる。上げないと、古いキャッシュのメッシュと計測時の読み直しで番号が食い違い、計測が別の面に当たる
