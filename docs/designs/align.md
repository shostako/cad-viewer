# 版の比較の位置合わせ（#59 P2）

2026-10-12。版の比較（`compare.md`）は、2 つの版が同じ座標系にあることを前提にしている。お客さんの改訂版が別の原点や向きで書き出されていると、全部の面が「変わった」と出る。#59 の要件は「位置合わせは手動基準点／基準面から始める。自動合わせは対称形状などの誤整列を考慮し、結果を確認・取り消せる」。この段では、手で選ぶ基準で合わせる。

## ほかの製品はどうしているか

| 製品 | 合わせ方 |
| --- | --- |
| SOLIDWORKS の Compare Geometry | 「Align parts」。両方の文書で座標系を 1 つずつ選び、それを重ねる。合う座標系が無ければ、それぞれの文書に作る |
| CloudCompare | 「Align (point pairs picking)」。対応する点を 3 組以上選び、最小二乗で合わせる。その後に「Fine Registration (ICP)」で詰める。ICP は、大まかに合っていることが前提（形の違う所は「遠い点を除く」で外す） |
| PolyWorks（IMAlign） | 対応する点を 3〜5 組、全体に散らし、いくつもの平面にまたがるように選ぶ。その後に best fit で詰める。合いの良さは標準偏差で見る |
| ZEISS INSPECT（GOM）など測定機の 3-2-1 | 1 つ目の基準（平面）で傾きと高さを決める。2 つ目（平面か直線）で回りを止める。3 つ目（点）で残りの位置を決める。丸い部品は、回りを止める直線の代わりに点（中心）を使う。自動の合わせ（プレアライメントから local best fit）は別の機能 |

- SOLIDWORKS: [Aligning Coordinate Systems](https://help.solidworks.com/2019/English/SolidWorks/sldworks/t_Aligning_Coordinate_Systems.htm)
- CloudCompare: [Align (point pairs picking)](https://www.cloudcompare.org/doc/wiki/index.php/Align)、[Fine Registration (ICP)](https://www.cloudcompare.org/doc/wiki/index.php/ICP)
- PolyWorks: [Registering (aligning) Scans in Polyworks V11 IMAlign](https://gmv.cast.uark.edu/scanning/software/polyworks/workflow-polyworks/registering-aligning-scans-in-polyworks-v11-imalign-2/)（アーカンソー大学の手順書）
- ZEISS: [Alignment 3-2-1](https://qualityforum.zeiss.com/topic/12958-alignment-3-2-1/)、[ZEISS の応用の資料](https://qualityforum.zeiss.com/migration/images/164_06bc71416ead86c74162f0728cd97fbf.pdf)

## この app でどうするか

**基準を順に選び、選んだ順を優先にして合わせる（3-2-1）。**

- 成形品の図面は、データム A|B|C（底の平面・位置決めの穴・もう 1 つの穴や長穴）で寸法を決めている。お客さんの改訂でも、基準は変わらないことが多い。同じ基準で合わせれば、図面の見方とそろう。
- 最小二乗（全部の基準を少しずつ）にすると、変わった所を基準に選んだとき、ほかの基準まで少しずつずれる。順に合わせると、1 つ目の基準は必ずぴったり合い、結果が予想できる。
- 点だけの合わせ（CloudCompare・PolyWorks の初めの段）は、角が丸い成形品では点を取りにくい。平面と穴の軸なら、B-rep の真値で取れる。

### 選べる基準

| クリックした物 | 基準 | 持つもの |
| --- | --- | --- |
| 平らな面 | 平面 | 外向きの法線、平面の上の点 |
| 円筒・円錐の面、直線の稜線 | 軸 | 向き（符号は無い）、線の上の点 |
| 円の稜線、円環の面 | 円 | 中心、軸の向き |
| 頂点、球の面 | 点 | 位置 |

- 値は backend（Web 版は `local/measure.ts`）の `face_info`・`edge_info`・`vertex_info` から取る（B-rep の真値）。平面の上の点は、`face_info` に `origin`（平面そのものの原点）として足す。
- 2 つの版で、同じ順に同じ種類を選ぶ。種類が違えば、選び直してもらう。
- 基準は 1〜3 個。3 個で、どの組み合わせでも動きが決まる（下の「合わせ方」）。

### 合わせ方

動かすのは比べる版。開いている版は動かさない（計測・注記・座標系は開いている版の上にある）。

1. **回転**：向きの列を、優先の順に作る。
   - まず、選んだ順に、平面の法線と、軸・円の向き。
   - 続けて、位置を持つ基準（軸・円・点）の 2 つ目から、1 つ目からの向き。軸の上では位置が決まらないので、軸の向きの成分は除く（2 本の平行な穴なら、穴から穴への向き）。
   - 列の 1 つ目の向きをぴったり合わせ、1 つ目と平行でない最初の向きで、1 つ目のまわりの回りを合わせる（座標系の Z と X と同じ。`frame.ts` の `makeFrame`）。
   - 軸の向きには符号が無い（穴の軸は、どちら向きに書かれているか分からない）。回す量の少ない方に取る。裏返しで合わせたいときは、平らな面を基準に入れる（面の法線は外向き）。
   - 向きが 1 つだけなら、それを合わせる最小の回転。1 つも無ければ回さない。
2. **移動**：選んだ順に、まだ決まっていない向きの分だけ合わせる。平面は法線の向きの 1 つ、軸は軸に直角な 2 つ、点と円は 3 つ。前の基準で決まった向きは変えない。
3. **決まらない動き**は、比べる版の真ん中（外形の箱の中心）を動かさない。たとえば平面 1 つだけなら、面どうしが重なるように傾きと高さだけを変え、横には動かさない。

例：A|B|C ＝ 底の平面・穴・穴。底の平面で傾きと高さ、1 つ目の穴の軸で横の位置、1 つ目の穴から 2 つ目の穴への向きで回りが決まる。

### 確かめと取り消し

- 凡例に出す：
  - 基準の組（「平面・軸・軸」）
  - 比べる版の動き（回転の角度と軸、真ん中の移動）
  - 基準のずれ（合わせた後の、それぞれの基準の離れと角度の最大）。対応しない物を選んだときは、ここが大きくなる
  - 基準で決まらなかった動き（「回転 1・移動 2」）
- 「位置合わせを外す」で、ファイルのままの位置に戻る。比較をやめる・別の版を読むと、合わせも外れる。
- 確認の記録の「版の比較」の表の注記に、位置合わせを書く。

### 選び方（画面）

1. 「基準で合わせる…」で、開いている版を出す（比較の色は隠す）。基準を順にクリックする。選んだ所に番号の札を立てる。Enter で次へ（基準 1〜3 個）、Backspace で 1 つ戻す、Esc でやめる。
2. 比べる版を、ファイルのままの位置で出し、視点をそれに合わせる。同じ順に同じ種類の物をクリックする。全部を選ぶと、合わせて比べ直す。
   - 比べる版の上のクリックには、開いている版と同じ選び方（頂点、近くの稜線、面）を使う（`picking.ts` の Picker を、比べる版の面と稜線にも向けられるようにする）。

### この段でしないこと

- STL などのメッシュの形式は B-rep の面が無いので、基準で合わせられない。次の段の自動の合わせで扱う。
- 尺度（mm とインチ）の違いは合わせない。

## 段

1. **この PR**：手で選ぶ基準（平面・軸・円・点、1〜3 個）で合わせる、凡例と記録、外す。テストは 3 つ。
   - `align.ts` の単体（作り方の分かっている動きで、3-2-1 の各組み合わせ、優先、決まらない動き、軸の符号）
   - pytest（平面の `origin` が平面の上にある）
   - E2E（テストデータの、回して動かした版を、基準で合わせると、合わせる前は全部が変わり、合わせた後は動かしていない版と同じ所が出る。種類の違う基準は断る。外すと戻る）
2. 自動の合わせ（点から面の ICP、外れの点を除く）。ファイルのままの位置か手の合わせから始め、対称な形で答えが幾つもあるときは知らせる。結果を確かめて取り消せる。
3. 剛体の位置ずれと形の変更の区別：合わせた動きを「位置のずれ」として出し、合わせた後の差を「形の変更」とする。
