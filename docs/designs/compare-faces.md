# 版の比較の面の変化（#59 P2）

2026-10-12。色の比較（`compare.md`）は「どこが、どちら向きに、どれだけ」離れたかを見せる。けれど、成形の図面で知りたいのは「何が、どう変わったか」のことが多い。穴を 5 mm 動かした改訂は、色では「元の穴の所が足された」「新しい穴の所が削られた」の 2 所になり、いちばん大きい差は穴の半径（3 mm）になる（`test_compare_cases.py` で確かめた）。「穴 R3 の軸が (20, 20) から (25, 20) へ 5.00 mm 動いた」と読めるほうがよい。#59 の「追加・削除・形状差を区別」の残り。

## ほかの製品はどうしているか

- SOLIDWORKS の Compare Geometry の面の比較：2 つの部品の面を組にし、片方にしかない面（赤）、両方にあるが少し違う面（黄）、同じ面（元の色）に分ける。組の面の頂点と面の上の点の位置を、許容の中かで比べる。報告に、片方だけの面と変わった面を載せる（[Unique Faces](https://help.solidworks.com/2025/English/swconntutorial/c_comparegeomuniquefaces_utilstut.htm)、[Options](https://help.solidworks.com/2025/English/swconntutorial/t_comparegeomoptions_utilstut.htm)）。
- 同じ Compare の「特徴の比較」は、特徴の名前が同じものどうしを比べる。お客さんから STEP で届く版には特徴の木が無いので、この app では使えない。

## この app でどうするか

B-rep の面を 2 つの版で組にし、同じ・変わった・片方だけに分ける（STEP・IGES どうし）。

- **面の一覧**：計測の口（`POST /measure`、Web 版は `local/measure.ts`）に、全部の面を一度に答える問い `{"type": "faces"}` を足す。中身は面ごとの `face_info`（種類と寸法：平面の法線と上の点、円筒の軸と半径、円錐の頂点と軸と角度、球の中心と半径、円環。面積と周り）と面の番号。`face_info` に面の重心（`centroid`）も足した。backend と Web 版は `npm test` で突き合わせる。
- **組にする**（`facecompare.ts`）：比べる版の面を、位置合わせの動きで開いている版の座標に移してから。許容は版の比較の許容。
  1. 同じ面：同じ曲面（種類が同じで、寸法が許容の中で同じ）で、面積の差が「周り × 許容」の中、重心が許容の中。いちばん近い物と組にする。
  2. 変わった面：残りの中で、片方が他方の変わった物と読める組を、動いた量の小さい順に取る。
     - 同じ曲面で面積や重心が違う：「形が変わった」（側面が高くなった、穴が足された面）
     - 平面で法線が同じ、位置が違う：「法線の向きに +0.50 mm 動いた」（肉厚の変更）
     - 円筒・円環で軸の向きと半径が同じ、軸の位置が違う：「軸が 5.00 mm 動いた（前 → 後）」。軸が同じで半径が違う：「半径 +0.50 mm」
     - 円錐（頂点・半角）、球（中心・半径）も同じ考え方
     - ただし、組の 2 つの面は互いの近くにあること（重心の離れが、大きい方の面の差し渡し（面積の平方根）より小さい。軸の動きは半径の 4 倍まで）。ピンの足とキャップの底は同じ平面にあるが、40 離れているので組にしない
  3. 片方だけ：組にならなかった面。部品の面が全部そうなら、部品として出す（「部品「cap」: 新しい版にだけある」）。もう一方の版に同じ曲面があれば、割れた面の片割れとして「形が変わった」にする（リブで 2 つに割れた上面）。
- **見せ方**：凡例に「面の変化（B-rep の面）: 同じ N 面・変わった M」と、変わった物を 1 行ずつ（5 行まで。残りは確認の記録）。行は種類の札（動いた・大きさが変わった・形が変わった・新しい版にだけ・前の版にだけ）と短い文（「円筒 R3.00: 軸が 5.00 mm」「平面 +Z: +0.50 mm」）。行を押すと、その面の重心へ寄って全文の札を出す。並びは、動いた → 大きさ → 新しい版だけ → 前の版だけ → 形が変わった、それぞれ量の大きい順。
  - 確認の記録に「面の変化」の表（種類・全文・重心）。
  - 新しいのは・許容・位置合わせを変えると作り直す。STL などのメッシュの形式どうしでは出さない。
- 色の比較はそのまま（面の変化は、その読み方を足す物）。
