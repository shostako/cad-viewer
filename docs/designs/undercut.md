# 型開き方向とアンダーカットの候補（#59 P2）

2026-10-12。#59 の P2「型開き方向とアンダーカット候補の検出」の最初の段。型開き方向へまっすぐ型を開くとき（2 枚の型）、どちらの型でも抜けない所（スライド・傾斜コア・無理抜きが要る所）を色で出す。

## ほかの製品はどうしているか

| 製品 | 判定 | 見せ方 |
| --- | --- | --- |
| SOLIDWORKS の Undercut Analysis | 引き抜く向きの上から見えない面（Direction1 undercut）、下から見えない面（Direction2 undercut）、どちらからも見えない面（Occluded undercut）、両方に勾配がある面（Straddle）、アンダーカットなし | 分類ごとの色。「Highlight occluded regions」で、面の一部だけ隠れている所は、その部分だけを塗る。向きは反転でき、三軸のハンドルで回して結果を見ながら変えられる。パーティングラインを向きの代わりにも使える |
| Moldflow の Design Adviser | ほかの形の影になる所。Z を型開き方向（XY 面をパーティング面）と決めている | 影を落とす側を赤、影になる側を青 |
| Fusion の Design Advice | 原点の軸から型開き方向を選び、反転できる | — |

- SOLIDWORKS: [Undercut Analysis](https://help.solidworks.com/2019/English/SolidWorks/Sldworks/c_mold_tools_undercut_analysis.htm)
- Moldflow: [Design Adviser analysis](https://help.autodesk.com/cloudhelp/2015/ENU/MoldflowAdvisor/files/GUID-D0A0D7D9-9F3D-48C7-8734-11DC53DF9E1B.htm)、[Undercut result](https://help.autodesk.com/cloudhelp/2015/ENU/MoldflowComm/files/GUID-244AB29C-040A-4D7F-A3D9-354799369774.htm)
- Fusion: [Design Advice](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/SLD-USE-DESIGN-ADVICE.htm)

## この app でどうするか

SOLIDWORKS と同じく、**見えるかどうか**で分ける。

- 表面の点ごとに、型開き方向の上（+d）と下（−d）へ光線を飛ばす。同じ部品に当たらずに抜けるかを見る。
  - 上へ抜ける：上の型で作れる。
  - 下へ抜ける：下の型で作れる。
  - 両方へ抜ける：型開き方向に平行な面。勾配が足りるかは、抜き勾配の色分けで見る。
  - **どちらへも抜けない：アンダーカットの候補。** スライド・傾斜コア・無理抜きが要る。
- 抜き勾配の「反対側」（青）は面の向きだけで決めているので、もう一方の型で抜ける面と、遮られて抜けない面を区別しない。アンダーカットの候補は、遮られる所だけを出す。#59 の完了条件「逆向きだが反対側の型で抜ける面と、指定方向で実際に遮られる領域を混同しない」はこれで満たす。
- 点は、版の比較と同じく、表示用メッシュを細かく割った頂点（`compare.ts` の `subdivide`）を使う。面の一部だけが影になる所（張り出しの下の床など）は、その部分だけを塗る。
- 光線の出発点は、点から面の外向きに少し（部品の大きさの 1/100000）離す。自分の面に当たらないようにするためだ。
- 部品ごとに見る。アセンブリのほかの部品は、別の型で作るので遮らない。
- 計算は Worker の中でする（three-mesh-bvh、手元の版も Web 版も同じ）。
- 見ないもの：パーティング面の位置、どちらが固定側か、スライドの向き、ナイフエッジ。次の段か、その先で考える。

## 見せ方

- 抜き勾配のフォルダに「アンダーカットの候補」を足す。入り切りで、型開き方向は「型開き方向」の選択を使う。
- **色**
  - アンダーカットの候補：赤紫（強い色）。
  - 上の型・下の型：抜き勾配の「抜ける側」「反対側」に合わせて、淡い緑・淡い青。
  - 両方：灰色。
- 凡例には、候補の面積と、判定の範囲（一方向の直線の引き抜き、2 枚の型、パーティングの位置は見ていない）を書く。
- カーソルの下には、その点の分類を出す。
- 抜き勾配の色分け、肉厚のヒートマップ、版の比較とは同時に使えない。

## 段

1. **この PR**：アンダーカットの候補の色（今の 6 方向）、凡例、カーソルの下の分類。
2. 型開き方向を、面・軸・ベクトルから決める（抜き勾配の色分けにも使う）。
3. 問題の一覧にアンダーカットの候補を出す（所ごとにまとめ、寄る）。確認の記録にも書き出す。
